# 계획
- 1 ~ 45 무작위 숫자 생성
- 생성된 숫자를 관리할 클래스
- 보너스 볼은 따로 관리
  - 5개 맞은 경우만 조회해서 판단.
- 사용자가 입력한 숫자를 관리할 클래스 -> Lotto 클래스로 이미 제공됨
- 등수별 상금을 관리할 enum
- 사용자가 상호작용할 view

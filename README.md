# 계획
- 1 ~ 45 무작위 숫자 생성
- 생성된 숫자를 관리할 클래스
- 보너스 볼은 따로 관리
  - 5개 맞은 경우만 조회해서 판단.
- 사용자가 입력한 숫자를 관리할 클래스 -> Lotto 클래스로 이미 제공됨
- 등수별 상금을 관리할 enum
- 사용자가 상호작용할 view

# 기능
- [x] 숫자 생성기
  - [x] 인수 n을 받아 n개의 1 ~ 45의 무작위 숫자 생성

- [ ] 사용자가 입력한 당첨 번호 일급 컬렉션
    - [ ] 생성된 숫자 리스트를 받고 몇개가 맞았는지 반환

- [x] 생성된 숫자 일급 컬렉션
    - [x] 당첨된 로또 필터
    - [x] 당첨된 금액 구하기
    - [x] 로또 당첨금 수익률

- [x] 숫자 일급 컬렉션 리스트를 관리할 일급 컬렉션
  - [x] 3개 이상 당첨된 로또 번호 일급 컬렉션 필터 후 반환

- [x] 당첨된 로또의 등수, 상금 판별 클래스
  - [x] 1 ~ 5 등까지의 갯수 반환
  - [x] 상금 enum 클래스에서 인수로 받고 상금을 곱해서 반환

- [x] 예외처리
  - [x] 1이하 45 초과인 경우
  - [x] 중복된 숫자
  - [x] 숫자가 아닌 문자
    - "," 는 허용
  - [x] 로또 숫자의 갯수 6개 초과
  - [x] 보너스볼이 로또 숫자와 중복
  - [x] 보너스볼이 범위 초과
  - [x] 보너스볼이 숫자가 아님

- [x] 입 출력
  - 입력
    - 사용자에게 입력받기
  - 출력
    - 생성한 로또 출력
    - 로또 결과 출력

- view Flow
  - 금액 입력
  - 번호 입력
  - 보너스 번호 입력
  - 생성된 로또 출력
  - 로또 다시 보내고 결과 반환 받기
